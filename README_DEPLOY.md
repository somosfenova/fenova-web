## Vercel
1. Crear un repositorio nuevo en GitHub (por ejemplo `fenova-web`).
2. Subir todo el contenido de esta carpeta a la raíz del repo.
3. En Vercel: Add New > Project > importar `fenova-web`.
4. Framework Preset: Other.
5. Build Command: dejar vacío.
6. Output Directory: dejar vacío.
7. Deploy.

Después agregar `fenova.com.ar` y `www.fenova.com.ar` en Settings > Domains.
