Política de Privacidad

Última actualización: 8 de septiembre de 2026.

Esta política explica cómo FENOVA trata la información que una persona decide enviar a través de fenova.com.ar para realizar una consulta comercial o solicitar información sobre nuestros servicios.

Qué información podemos recibir

Dependiendo del medio de contacto elegido, podemos recibir nombre, empresa o negocio, correo electrónico, teléfono o WhatsApp, el texto de la consulta y, cuando el usuario elige grabarlo, un archivo de audio y su duración.

Para qué utilizamos la información

La utilizamos para comprender la consulta, contactar al interesado, preparar propuestas, realizar seguimiento comercial, mejorar nuestros servicios y mantener un historial interno de las conversaciones relacionadas con una oportunidad comercial.

Audios

Los audios se almacenan en infraestructura privada y no se publican. El acceso operativo se limita al panel interno de FENOVA mediante enlaces temporales de reproducción.

Proveedores tecnológicos

Para operar el sitio podemos utilizar servicios tecnológicos de terceros, entre ellos Vercel para alojamiento y funciones web y Supabase para base de datos y almacenamiento. Estos proveedores procesan información de acuerdo con sus propias condiciones y medidas de seguridad.

Analítica, medición y campañas

FENOVA puede utilizar herramientas de medición como Google Tag Manager y, cuando se active, Google Analytics, además de tecnologías publicitarias como Meta Pixel, para comprender de forma agregada cómo se utiliza el sitio, medir el rendimiento de campañas y mejorar la experiencia.

Podemos registrar datos técnicos y de atribución como páginas visitadas, tipo de dispositivo o navegador, fuente de la visita, parámetros UTM, identificadores publicitarios de clic, página de entrada y sitio de referencia. Cuando corresponda, las herramientas de Google se configuran con señales de consentimiento para limitar el uso de almacenamiento analítico y publicitario.

Google Tag Manager funciona como un contenedor técnico para administrar etiquetas del sitio. No se utiliza para almacenar directamente los datos de contacto que una persona completa en los formularios de FENOVA.

Conservación

Conservamos la información durante el tiempo razonablemente necesario para atender la consulta, realizar seguimiento comercial y cumplir obligaciones aplicables. La información puede eliminarse cuando deja de ser necesaria.

Derechos y contacto

Podés solicitar acceso, corrección o eliminación de información asociada a tu consulta escribiendo a somosfenova@gmail.com. Cuando resulte aplicable, trataremos estas solicitudes conforme a la normativa argentina de protección de datos personales.

Seguridad

Aplicamos medidas razonables para limitar accesos no autorizados. Ningún sistema conectado a Internet puede garantizar seguridad absoluta, por lo que revisamos y mejoramos nuestras medidas a medida que evoluciona el servicio.
